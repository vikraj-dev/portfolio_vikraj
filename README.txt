FLUTTER & PHP DEVELOPER PORTFOLIO
==================================

HOW TO USE
----------
1. Just double-click "index.html" to open it in any browser.
2. To put it online, upload "index.html" to any web host
   (Netlify, Vercel, GitHub Pages, Hostinger, etc.) - it's a
   single self-contained file, no build step needed.

WHAT TO EDIT (open index.html in any text editor)
---------------------------------------------------
- Your name: search for "Alex Menon" and replace everywhere.
- Bio / tagline: the <h1> and <p class="lede"> inside the
  <section class="hero"> block.
- Contact details: search for "your.email@example.com",
  "+91 00000 00000", GitHub and LinkedIn links inside
  <section id="contact">.
- 9 mobile app cards: inside <div class="proj-grid" id="apps">
  - each <div class="app-card"> is one project. Replace the
  "Project One / Two / ..." titles and description text.
- 3 web platform cards: inside <div class="proj-grid hidden" id="webs">.
- Experience timeline: inside <section id="experience">.
- Your photo: it's already embedded (base64) inside the
  <div class="photo-frame"> - to change it, replace the <img src="...">
  with a new photo (upload it somewhere and paste the URL, or
  convert a new image to base64 and paste it the same way).

Built with: HTML, CSS, vanilla JS, and Three.js (loaded from CDN)
for the 3D visuals. No frameworks, no build tools - just open and go.
